# Harness Doc Structure

Each file in `docs/harness/` documents one source file in `src/rtl_comrade/`. The expected structure is:

- **Source** link
- **Role** — one paragraph on what the file does
- **See Also** — links to related harness docs
- **Main Responsibilities** — bullet list
- **Place In The System** — how it fits into the overall flow
- **Key Behaviors / Notable Behaviors** — anything non-obvious
- **Caveats** — known limitations, sharp edges, things that would surprise a reader
